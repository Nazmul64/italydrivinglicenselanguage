# 🚗 MBanglaPatenteB (Italy Driving License Platform)

A high-performance Laravel application & Flutter mobile backend for Italian Driving License (Patente B) preparation with Italian-Bangla bilingual study cards, practice test simulations, road signs (cartelli), interactive vocabulary dictionary, and cross-platform synchronization.

## 📚 Documentation
- **Official RESTful API Documentation & Mobile Integration Guide**: [RESTFUL_API_DOCUMENTATION.md](file:///f:/mbanglabatentebmainsite/RESTFUL_API_DOCUMENTATION.md)

## 🚀 Key Features
- **Bilingual MCQ Cards & Audio**: Italian question text with underline dictionary keywords and voiceover audio.
- **2-Way Real-time Sync**: Automatic sync for Saved MCQs, Personal Notes, Correct Questions, and Wrong MCQs across Web PWA and Flutter Mobile App using phone identification (`X-Client-Phone`).
- **QR Code Security**: QR scan instant browser unlock requiring active admin-approved license (`is_active == 1`).
- **Official Scheda Esame**: 30-question standard exam simulation with timer, error counting, and result summary.
